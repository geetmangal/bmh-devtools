About CIDR notation

Classless Inter-Domain Routing (CIDR) writes an address and the number of leading network bits, for example 192.168.10.0/24. The remaining bits identify hosts: a /24 leaves 8 host bits (256 addresses), a /22 leaves 10 (1024 addresses). In IPv4 two addresses per subnet are reserved for the network and broadcast addresses, so a /24 has 254 usable hosts, except for /31 point-to-point links and /32 single hosts. IPv6 has no broadcast; the all-zeros interface identifier is the subnet-router anycast address.

The same calculation is available as JSON: POST /api/v1/subnet/calc {"cidr": "10.0.0.0/22"}, POST /api/v1/subnet/split {"cidr", "new_prefix"} and POST /api/v1/subnet/summarise {"cidrs": [...]}. Planning private networking for a BookMyHost VPS? A /24 per project is a sensible default.
