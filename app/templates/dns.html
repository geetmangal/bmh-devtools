DNS Propagation Checker

Check whether a DNS change has reached public resolvers around the world, including Indian anycast nodes, and compare each answer with the zone's authoritative nameserver. Supports A, AAAA, CNAME, MX, NS, TXT, SOA and PTR records.

How DNS propagation works

When you change a record at your DNS provider, the authoritative nameservers answer with the new value immediately. Recursive resolvers run by ISPs and public DNS operators, however, keep the previous answer in cache until its TTL (time to live) expires. This checker queries 18 recursive resolvers in parallel with a 2 second timeout each and marks every one that already returns the same record set as the authoritative server as propagated.

Tip: before migrating a website or mail server to a new cloud server, lower the TTL to 300 seconds at least 24 hours in advance, then raise it again after the move.
